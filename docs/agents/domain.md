# Domain docs

## Layout

This repository uses a single-context layout:
- GLOSSARY.md at the repository root.
- Architecture decision records in docs/adr/.

## Before exploring

Read GLOSSARY.md and the ADRs relevant to the work.
If they do not exist, proceed silently.
Create domain documents when terms or decisions are resolved.

## Vocabulary and decisions

Use the glossary's terms in issues, proposals, hypotheses,
and tests. Identify meaningful vocabulary gaps.

Surface conflicts with an existing ADR explicitly, naming
the ADR and explaining why its decision should be reconsidered.
